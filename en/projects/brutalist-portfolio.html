Brutalist Portfolio

An unapologetic, raw, and minimalist portfolio website designed to showcase my creative and technical abilities through a brutalist design aesthetic. Featuring a custom right-click context menu, kinetic sliding accordion sections, zero-dependency vanilla performance, and serverless contact integrations.

01 The Brutalist Concept & Creative Identity

In a web ecosystem saturated with cookie-cutter templates, rounded pastel cards, and bloated UI frameworks, this portfolio is a deliberate statement in digital brutalism.

The design embraces stark high-contrast monochrome tones, sharp geometric borders, raw typography (Cossette Titre + Monospace), and tactile kinetic animations. It is engineered to capture immediate attention, reflecting an authentic passion for unconventional front-end experimentation.

02 Signature UI Interactions

Beyond aesthetic minimalism, the portfolio incorporates custom interactions crafted purely in vanilla JavaScript:

FEATURE 01 UX Easter Egg

Custom Right-Click Context Menu

Intercepts browser contextmenu events to render a sleek brutalist floating navigation menu directly under the cursor.

FEATURE 02 State Engine

Kinetic Accordion Sections

Sections slide open and closed with fluid CSS height animations triggered by navigation buttons, hash URLs, and headings.

FEATURE 03 Serverless Pipeline

Web3Forms + hCaptcha

Direct asynchronous API messaging integration with bot protection and dynamic modal notifications.

FEATURE 04 Visual Arts

ASCII Art Stargate

Integrated handcrafted monochrome ASCII art graphics reflecting classic hacker and terminal aesthetics.

03 Zero-Bloat Vanilla Architecture

Delivering instant page speeds and perfect SEO scores by stripping away unnecessary JavaScript runtime overhead:
