Chucky's Website

01 Project Overview & Academic Goals

In modern web development, writing code is only half the battle — understanding how applications are served, configured, and maintained on live remote servers is a fundamental discipline.

This project was conceived as an end-to-end practical exercise in remote systems administration and vanilla web development. The goal was to build a complete interactive website themed around the classic horror franchise and manage its lifecycle on an Alwaysdata Linux server instance.

02 Server Administration & Deployment Pipeline

The core learning outcome of this project was mastering server communication protocols and directory permissions:

STEP 01 Alwaysdata Setup

Environment Provisioning

Configured a remote Linux hosting space on Alwaysdata, establishing subdomains and mapping web root directories.

STEP 02 Security & Access

SSH Key Authentication

Generated RSA key pairs to enable secure passwordless terminal access to remote files and directory management.

STEP 03 File Transfer

FTP / SFTP Workflows

Managed automated asset synchronization and staging deployments using FileZilla and terminal SFTP clients.

STEP 04 Diagnostics

HTTP Headers & Permissions

Verified chmod file permissions (755 / 644), analyzed Apache server response headers, and debugged 404/500 routing.

03 Zero-Dependency Frontend Architecture

The frontend was intentionally engineered without frameworks or third-party build tools to maximize raw performance and demonstrate mastery of fundamental web standards:

// Server Deployment & Tech Specifications Hosting Platform: Alwaysdata Linux Cloud Instance Protocols: SSHv2 (Encrypted Shell), SFTP / FTP Over TLS Markup / Layout: Semantic HTML5 + CSS3 Flexbox & Grid Scripting: Native JavaScript (ES6 Modules, DOM Events) Asset Optimization: Lossless image compression & minimal HTTP requests Browser Support: Chrome, Firefox, Safari, Edge (Evergreen & Legacy)

04 Key Takeaways & Competencies

  • Full Linux Server Lifecycle Hands-on expertise configuring web roots, virtual hosts, and DNS records on remote servers.
  • Secure Shell (SSH) Proficiency Comfortable with terminal navigation, file manipulation, and key-based authentication.
  • Lightweight Vanilla Performance Zero build steps, blazing fast page loads, and zero JavaScript runtime bloat.
  • Multi-Device Responsive Design Pixel-perfect rendering across mobile phones, tablets, and desktop resolutions.
