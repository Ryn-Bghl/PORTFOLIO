Landing Page of IUT Sénart Fontainebleau

01 The Challenge & Creative Brief

University websites frequently struggle with information density: students, prospective applicants, and faculty members often have to navigate through dense multi-tiered menus to locate essential academic tracks, campus life details, or admissions procedures.

The brief was an open creative workshop to conceptualize and code an imaginary, dynamic landing page for the IUT of Sénart Fontainebleau. The core challenge was distilling complex departmental offerings into clean, easily scannable sections with bold typographic hierarchy and clear calls-to-action.

02 Design Process & Strategy

I approached the challenge from both a UX psychology angle and front-end engineering perspective:

PHASE 01 Auditing

Audience Personas

Segmented high-priority user journeys: high-school graduates looking for BUT programs, current students checking schedules, and business partners seeking apprentice talents.

PHASE 02 Wireframing

Information Architecture

Structured an engaging hero banner, program discovery cards, campus highlights, and a persistent contact/orientation anchor to maximize user engagement.

PHASE 03 Implementation

CSS Grid & Flexbox

Engineered modular, reusable layout components with CSS Grid and modern CSS properties to ensure consistent spacing and robust multi-column alignment.

PHASE 04 Deployment

Hosting & Validation

Deployed to live Alwaysdata web hosting, tested cross-browser compatibility across Chrome, Firefox, and Safari, and optimized layout performance.

03 Layout Systems & Technical Highlights

The layout uses clean semantic HTML5 containers paired with modular CSS utility patterns for quick rendering and zero dependency overhead:

// Core Layout Specifications Typography: Clean sans-serif headings with high-contrast legibility Grid System: CSS Grid with dynamic `minmax()` column wrapping Navigation: Sticky accessible header with direct anchor jumping Performance: 100% Native CSS/HTML without external UI frameworks Deployment: Alwaysdata Linux Web Server

04 Key Features & Highlights

  • Streamlined Information Architecture Translates dense educational curricula into digestible cards and concise program summaries.
  • Targeted Call to Actions Highlights Open Day dates, registration deadlines, and candidate application portals.
  • Mobile-First Responsiveness Ensures prospective students browsing on smartphones enjoy an uncompromised experience.
  • Lightweight Native Codebase Delivers lightning-fast load times without relying on heavy UI libraries.
