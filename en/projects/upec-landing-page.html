Landing Page of IUT Sénart Fontainebleau

A creative challenge exploring how university web portals can be reimagined for modern student audiences. This conceptual landing page for the IUT de Sénart Fontainebleau (UPEC) re-architects academic information into a high-impact, user-friendly, and responsive web experience.

01 Context & Creative Vision

Higher education websites often suffer from cognitive overload — multi-layered menus, dense text walls, and fragmented navigation paths that obscure critical information like degree tracks, admission deadlines, and campus facilities.

The objective of this workshop project was to design and develop a contemporary landing page concept for the IUT de Sénart Fontainebleau, prioritizing instant clarity for prospective high school students, current undergraduates, and corporate apprenticeship partners.

02 Design Strategy & Grid Architecture

The layout was built around the principle of progressive disclosure — surfacing high-priority information first, supported by clean modular cards and bold typography:

PILLAR 01 Information Architecture

Student-Centric Hierarchy

Reorganized university departments into digestible categorical pillars with direct admission links.

PILLAR 02 Layout Engineering

CSS Grid Systems

Employed modern CSS Grid with fluid fractional tracks (fr) and clamp() formulas for scalable viewports.

PILLAR 03 Typography

High-Contrast Legibility

Selected high-contrast type scales ensuring effortless scanning across both small mobile screens and large monitors.

PILLAR 04 Branding

Academic Identity

Harmonized UPEC's institutional colors with modern brutalist accents and structured card borders.

03 Frontend Implementation Details

The design was translated into lightweight, accessible HTML5 and modern CSS3, avoiding extraneous frameworks:

// Layout Engine Specifications Layout Paradigm: CSS Grid (auto-fit, minmax) + CSS Flexbox Fluid Typography: clamp(1rem, 2.5vw, 2.5rem) for seamless scaling Accessibility: WAI-ARIA landmark roles, tabindex ordering, semantic markup Server Target: Alwaysdata Linux Hosting Environment Zero Dependencies: Pure vanilla HTML & CSS architecture

04 Key Features & Highlights

  • Streamlined Department Navigation Quick-access modules for MMI, GEA, TC, and other BUT specializations with clear admission criteria.
  • Adaptive Responsive Layout Fluid CSS Grid dynamically rearranges content across breakpoints without horizontal overflow.
  • Institutional Visual Polish Modern typographic rhythm that balances academic seriousness with fresh, engaging web design.
