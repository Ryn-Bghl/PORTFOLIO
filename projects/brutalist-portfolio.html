Brutalist Portfolio

An unapologetic, raw, and minimalist portfolio website designed to showcase my creative and technical abilities through a brutalist design aesthetic. Featuring a custom right-click context menu, kinetic sliding accordion sections, zero-dependency vanilla performance, and serverless contact integrations.

01 Design Vision & Philosophy

Most contemporary web portfolios follow identical cookie-cutter design templates with soft gradients, rounded cards, and generic animations. My goal was to rebel against this visual monotony by embracing Web Brutalism: an aesthetic celebrating raw functionalism, stark black-and-white contrast, monospaced typography, solid 1px geometric borders, and crisp tactile drop shadows.

Beyond aesthetics, the site is designed to feel alive and interactive with bespoke touches—like a custom operating-system style right-click context menu, kinetic accordion navigation, and subtle grayscale-to-color image hover interactions.

02 Interactive Architecture & Development

Every interaction was hand-coded using vanilla JavaScript and modern CSS with zero heavy third-party libraries:

FEATURE 01 Context Menu

Custom Right-Click Navigation

Intercepts the browser's native `contextmenu` event to render a custom styled floating brutalist navigation box at the exact click coordinates.

FEATURE 02 Accordion UI

Kinetic Section Transitions

Engineered CSS keyframe animations (`openSection`/`closeSection`) allowing seamless toggling between Home, About, Projects, and Contact sections in a single unified viewport.

FEATURE 03 Serverless Forms

Contact API & Spam Protection

Integrated Web3Forms API paired with hCaptcha and custom modal popup notifications for real-time message delivery without requiring a dedicated backend server.

FEATURE 04 Performance

Zero Dependency Speed

By leveraging native HTML5/CSS3/ES6 JS, the entire website bundle is ultra-lightweight, achieving near-instantaneous load times on any network connection.

03 Technical Implementation Highlights

Here is an example snippet showing how the custom right-click context menu is created dynamically on coordinates:

// Custom Brutalist Context Menu Implementation document.addEventListener("contextmenu", (event) => { event.preventDefault(); if (document.querySelector("#context_menu")) { document.querySelector("#context_menu").remove(); } const contextMenu = document.createElement("div"); contextMenu.id = "context_menu"; contextMenu.style.position = "absolute"; contextMenu.style.top = `${event.pageY}px`; contextMenu.style.left = `${event.pageX}px`; contextMenu.innerHTML = ` <nav> <ul> <li><button id="context_home">home</button></li> <li><button id="context_about">about</button></li> <li><button id="context_projects">projects</button></li> <li><button id="context_contact">contact</button></li> </ul> </nav> `; document.body.appendChild(contextMenu); });

04 Key Features & Highlights

  • Bespoke Context Menu Navigation Provides users with an unconventional, desktop-app-like interactive navigation model.
  • Smooth Kinetic Accordion Dynamically collapses and expands full-height sections with smooth easing curves.
  • Dedicated Case Study Pages Individual intern project pages providing rich technical context, live preview links, and process steps.
  • Serverless Contact Submissions Direct inbox routing with automated validation, hCaptcha protection, and confirmation popups.
