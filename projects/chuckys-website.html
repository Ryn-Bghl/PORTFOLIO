01 Project Overview & Academic Goals

This project was developed as part of the BUT MMI curriculum to master full-lifecycle web deployment beyond local development sandboxes. The primary objective was not only creating an immersive themed web interface celebrating the iconic "Chucky" universe, but mastering remote Linux server infrastructure, secure key generation, command line access, and multi-environment file management.

02 The Process & Systems Administration

Rather than relying on automated black-box deployment systems, this lab required hands-on configuration of network protocols and server permissions:

STEP 01 Authentication

SSH Key Pair Generation

Generated RSA/Ed25519 cryptographic key pairs, configured public keys on the Alwaysdata server host, and established passwordless terminal sessions.

STEP 02 Protocols

FTP / SFTP Setup

Configured secure FTP user accounts, directory permissions (`chmod`/`chown`), and synchronization pipelines for efficient file deployment and remote file tree management.

STEP 03 Frontend

Native Web Coding

Crafted semantic HTML5 markup, structured responsive CSS stylesheets with fluid breakpoints, and added lightweight JavaScript for DOM interactivity.

STEP 04 Audit & QA

Cross-Device Verification

Tested server response headers, caching configurations, and visual fidelity across mobile, tablet, and desktop viewports.

03 Technical Architecture & Server Workflows

Building without bloated frameworks allowed for a deep appreciation of standard browser mechanics and server response lifecycles.

04 Key Takeaways & Learned Skills

  • Server Infrastructure & SSH Mastered remote command-line terminal navigation, SSH key management, and Linux directory security.
  • FTP / SFTP File Pipelines Gained hands-on experience synchronizing production assets and configuring server access controls.
  • Zero-Dependency Performance Achieved near-instant page load speeds by leveraging lightweight native web standards.
  • Adaptive Responsive Design Structured media queries providing a comfortable browsing experience on all screen dimensions.
