BattleShip-Algo

An algorithmic game engine and interactive web simulator designed to explore ship placement algorithms, probabilistic targeting heuristics, and optimal search strategies for the classic game of Battleship.

01 Project Overview & Objectives

Battleship is traditionally seen as a guessing game, but under the hood, mathematically optimal targeting can be achieved through probability density matrices and parity search heuristics.

I developed BattleShip-Algo to test and benchmark various placement and search algorithms against randomized and strategic defensive boards, visualizing how AI agents evaluate probabilities across 10x10 grids in real-time.

02 Algorithm Design & Process

The simulation was built by modeling the mathematical states of the board at each turn:

STAGE 01 Grid Matrix

Collision-Free Grid Generation

Engineered pseudo-random ship placement algorithms enforcing boundary checks, orientation variance, and distance constraints.

STAGE 02 Hunt Phase

Parity & Checkerboard Search

Implemented parity-based coordinate scanning (firing only on alternating diagonal cells) to guarantee finding the smallest remaining ship with minimum shots.

STAGE 03 Target Phase

Directional Probability Heuristic

Once a hit is registered, the algorithm switches to a directional target mode, prioritizing collinear adjacent cells until the ship is fully sunk.

STAGE 04 Visualization

Interactive Web Dashboard

Built a responsive UI that displays real-time hit/miss rates, total moves taken, and probability density overlays across the board.

03 Mathematical Strategy Breakdown

// Core Heuristic Workflow: 1. Hunt Mode: Calculate probability density map of all surviving ship permutations. 2. Filter: Eliminate impossible orientations based on previous misses and board edges. 3. Fire: Target coordinate with highest statistical density (Parity Optimized). 4. Target Mode: On hit, immediately queue adjacent orthogonals (North, East, South, West). 5. Repeat until all 5 ships (Carrier, Battleship, Cruiser, Submarine, Destroyer) are eliminated.

04 Key Features & Highlights

  • Heuristic AI Targeting Significantly reduces average shot count needed to win compared to random sampling.
  • Dynamic Probability Density Calculation Recalculates likelihood heatmaps across all remaining valid configurations every turn.
  • Clean Interactive Interface Allows real-time visual inspection of the algorithm's decision-making process.
  • Lightweight Vanilla Architecture Fast execution in any web browser without third-party frameworks.
